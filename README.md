# learning-notes

Minimal notes on concepts, written to refresh the mind quickly: a one-line core, a few key points,
a diagram or mind map and one example. Written with a tutor agent for Claude Code.

## Layout

```
notes/            the notes, grouped by topic (notes/<topic>/<concept>.md)
notes/README.md   index, one line per note
templates/        note template
agents/ skills/   the tutor agent brief and its learn-fast skill
scripts/          check-public.sh (privacy scan), publish.sh (checked publish)
```

## Browse

Start at [notes/README.md](notes/README.md). Diagrams are Mermaid and render on GitHub.
